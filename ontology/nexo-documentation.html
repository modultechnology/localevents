Description

An ontology for modeling both simple scheduled events (concerts, exhibitions, conferences) and complex unscheduled societal phenomena (social movements, pandemics, conflicts, natural disasters). NEXO focuses on Earth-based events across domains including: - Cultural events (exhibitions, concerts, performances) - Sports events (matches, races, tournaments, marathons) - Criminal incidents (shootings, stabbings, assaults) - Armed conflicts (wars, battles, military operations) - Social movements (protests, civil rights movements) - Public health crises (pandemics, epidemics, outbreaks) - Environmental events (natural disasters AND human-caused) - Financial events (market crashes, IPOs, bankruptcies, M&A) - Conference events (scientific, business, political summits) - Life events (deaths, obituaries of notable people) - Legal/judicial events (trials, verdicts, court decisions) - Accidents (transportation, industrial, non-criminal) - Technology events (product launches, software releases) - Recognition events (awards, honors, prizes) - Electoral events (elections, referendums) - Diplomatic events (treaties, agreements, accords) Design Principles: 1. Minimal commitment - allows underspecification 2. Event granularity - supports atomic and composite events 3. Temporal flexibility - handles both precise dates and fuzzy periods 4. Multiple perspectives - accounts for contested interpretations 5. Emergence - captures how events develop and evolve 6. Causality - natural vs. human-caused distinction 7. Earth-centric - designed for terrestrial events (extensible to space)

Abstract

NEXO models events as they are reported in narrative text. It covers eighteen domain families and provides a shared spine for temporality, spatiality, participation, causality, composition and perspective, so that domain branches specialise a single event model rather than each inventing their own.

Version 1.2 adds Mobility and Legislative branches, refines the cultural and
sports branches, widens several ranges to admit the unnormalised surface
forms that text extraction actually yields, and repairs classes that v1.1
declared but left unreachable. Corpus-specific bindings live in optional
modules; the core has no dependency on any particular dataset.
